# 迷宮小冒險的聲音

所有聲音都是用程式合成的（numpy、scipy）：沒有錄音、沒有下載別人的素材，八首曲子都是為這個 APP 新寫的。

- 合成用的小工具（鐘聲、木琴、撥弦、玩具小喇叭、接成循環、量音量、人聲的共鳴方法……）是從眼尖尖大挑戰的 `design/sounds/make_sounds.py` 複製過來的（它們大多又是從想一想樂園、小卡認天下、動物小餐廳、字母寵物來的）；泡泡、玻璃珠「叮」、木頭「叩」、毛氈鋼琴是從想一想樂園來的。
- 新做的有：陶笛、斑鳩琴（banjo）、直笛、豎琴、低音管（bassoon）、鋼鼓、手風琴、玩具鋼琴、電子鈴、太空口哨（像特雷門琴，一個音滑到下一個音）、哼歌的聲音、雪橇鈴、拍手、會繞回開頭的山洞回聲，八首曲子，以及其他的聲音。

給 2～5 歲的小朋友，所以**好玩、溫暖、柔和**：沒有刺耳或突然的聲音；手指滑出路外只是很輕、很友善的「咚～」，不是答錯的警告聲，也不會嚇人。

做的時候沒辦法用耳朵聽，是看數字（長度、音量、破音、接頭）和頻譜圖（聲音裡每個高低的音在什麼時候出現）檢查的；請在手機上聽聽看，覺得哪個不好聽再改。

## 怎麼產生

```
pip install numpy scipy                                     # 只要第一次
python3 design/sounds/make_sounds.py                        # 寫到 app/assets/sounds/*.wav
python3 design/sounds/make_sounds.py preview 試聽.m4a        # 再做一個試聽檔（要 ffmpeg）
```

跑完會印出每個檔案的長度、大小、最大音量、聽起來多大聲、有沒有破音、頭尾的點，還有背景音樂接頭的檢查，和旋律比伴奏響多少。
- 亂數都用固定的種子，每次跑出來的檔案都一模一樣（一個 byte 都不差）。
- 程式會檢查：檔名剛好是下面這些（資料夾裡沒有別的檔案）、腳步聲不超過 0.25 秒、音效不超過 1.5 秒、背景音樂 16～20 秒、音效和腳步聲頭尾都是 0、沒有破音、背景音樂的接頭沒有「啪」一聲。
- 全部加起來超過 5,000,000 bytes 就會停下來報錯。八首 16 秒以上的背景音樂（每秒 16,000 個點）光是音樂就要 4.1 MB，所以上限比兄弟 APP 大一點。
- 試聽檔是每首背景音樂的前 5 秒，接著每個腳步聲照走路的樣子連播 4 次（每 0.3 秒一次），再每個音效照順序播一次，中間停一下；會印出每一段從第幾秒開始。

## 格式
- 全部是 WAV、單聲道、16 位元。
- 背景音樂 16,000 Hz；腳步聲和音效 22,050 Hz。
- 背景音樂都是整數小節，可以無縫循環：曲子結尾還在響的聲音接回開頭，聽不出接縫（山洞的回聲也是繞回開頭）。程式用兩個方法檢查接頭：最後一個點跳回第一個點的差距（要比接頭前後 0.02 秒裡最大的一步小），和接頭前後 0.02 秒的高音（如果有「啪」一聲會在這裡冒出來；要比曲子其他地方最響的一段小很多）。
- 腳步聲和音效兩頭都有淡入淡出，第一個和最後一個點都是 0，不會「啪」一聲。
- **音量一樣大**：程式量每個聲音「從手機喇叭聽起來」有多大聲。
  - 怎麼量：用耳朵比較敏感的頻率（A 加權）、不算手機放不出來的低音，大約 0.2 秒一段（耳朵大約這樣把聲音加起來）。
  - 再把每個聲音調到一樣大聲（約 −21 dB）：該輕一點的就小幾 dB。例如按鈕、下一關、翻頁比較輕（−25 dB），手指滑出路外更輕（−27 dB）。
  - 最大音量不超過 0.72。
  - 也量了用耳機或平板聽（不扣手機放不出來的低音）：每個聲音和用手機聽差不到 1.2 dB，換裝置也不會有哪個突然特別大聲。
  - 和兄弟 APP 的音效差不多大聲。
- **腳步聲**每走一格播一次，一直重複，所以很短（0.13～0.18 秒）、很輕（−28～−29 dB，比音效輕 7～8 dB），頭尾圓圓的，連著聽不會吵。
- 背景音樂聽起來比音效輕約 8 dB（首頁 −29 dB；六個世界 −30 dB，城市比較熱鬧所以再輕一點 −30.5 dB；休息的搖籃曲 −30 dB），放在念的話和音效下面。
- 每首曲子的旋律比伴奏響約 11～12 dB（搖籃曲 10 dB），旋律清楚，伴奏也聽得到。
- 手機小喇叭放不出很低的聲音。所以挖土、公車、企鵝的腳步聲、撞到的「咚」、到家的低音、「咕？」這些低低的，都加了一點它自己比較高的泛音（也就是聲音裡比較高的那些成分），手機上才聽得到；地底隧道的低音管放在它比較高、比較亮的音域。
- 全部 29 個檔，加起來約 4.5 MB（4,716,200 bytes），在 5 MB 以內。

## 背景音樂

八首的拍子、調、樂器都不一樣，小朋友一聽就知道自己在哪一個世界；也和兄弟 APP 的曲子都不一樣（旋律都是新寫的；B 大調和降 G 大調兄弟 APP 都沒用過）。

| 檔案 | 用在哪裡 | 長度 | 聽起來 |
|---|---|---|---|
| `music_home` | 首頁（世界地圖，和土豆一起） | 16.6 秒 | 友善的散步曲，「出發囉！」：四拍子、G 大調，不快不慢。陶笛唱旋律（開頭 Sol–Si–Re 一階一階往上跳，像開心的腳步），撥弦低音每一拍走一步，斑鳩琴在二、四拍刷和弦，輕輕的鼓和沙鈴跟著走。後半首鐵琴在拍子上叮叮跟著，斑鳩琴在中間多彈一下；最後一小節順著 D7 和弦走下來，接回開頭 |
| `music_garden` | 花園（小蜜蜂） | 16.3 秒 | 春天、陽光、一搖一擺：6/8 拍、D 大調。直笛唱旋律，豎琴把每個和弦上上下下撥成水波，撥弦低音在兩個大拍上，沙鈴很輕。後半首鐵琴高八度輕輕跟著唱 |
| `music_tunnel` | 地底隧道（土豆的家） | 16.6 秒 | 溫暖、有一點躡手躡腳：四拍子、E 多利安調（小調，但有一個亮亮的音，聽起來像民謠，不會悲傷）。低音管吹短短、彈彈的音；低低的馬林巴琴「咚．．噠咚」，加一點撥弦低音；木頭在二、四拍「叩」一聲像小鏟子拍土；沙沙聲像土在流；偶爾高高的地方有寶石「叮」一閃。整首有一點山洞的回聲，高音收暗一點 |
| `music_sea` | 海底（小魚） | 16.0 秒 | 陽光的加勒比海 calypso：四拍子、F 大調，「三、三、二」的節奏。鋼鼓唱旋律（長的音像真的鋼鼓手一樣快速連敲），低一點的鋼鼓在「三、三、二」上敲和弦，低音彈彈跳跳，沙鈴打拍子；每半首結尾泡泡咕嚕咕嚕往上冒 |
| `music_city` | 城市（小公車） | 16.0 秒 | 熱鬧、開心的搖擺（shuffle，一長一短像車輪轉）：四拍子、A 大調。手風琴（兩片簧片差一點點，聲音會微微閃動）唱旋律；低音在一、三拍「嗡」，毛氈鋼琴在二、四拍「巴」，輕輕的拍手和搖擺的沙鈴；第四小節旋律停下來的地方，公車「叭叭！」兩聲 |
| `music_snow` | 雪地（小企鵝） | 16.3 秒 | 溜冰的圓舞曲：三拍子、B 大調。玩具鋼琴叮叮噹噹唱旋律；撥弦「嗡－巴－巴」；雪橇鈴在「巴、巴」上輕輕搖；像玻璃一樣的長音墊著每個和弦；第 1 和第 9 小節三角鐵「叮～」；後半首鋼片琴低八度跟著唱 |
| `music_space` | 太空（太空人） | 16.6 秒 | 在星星中間飄：四拍子、降 G 大調，慢慢的、像在作夢（第二個和弦借了一個升高的音，聽起來有太空感）。柔柔的太空口哨（像特雷門琴）從一個音滑到下一個音；電子鈴把每個和弦上上下下慢慢閃，後面跟著一點回聲；溫暖的長音發著光；圓圓的低音在一、三拍；高高的地方小星星偶爾「叮」一下 |

| `rest` | 休息時間到了 | 1.48 秒 | 土豆打哈欠「哈～啊～嗯」（小小的、有氣音，往下沉，嘴巴慢慢閉起來變成哼），再鋼片琴輕輕往下 Sol–Mi–Do，像躺進被窩 |
| `page` | 翻貼紙冊 | 0.24 秒 | 紙翻過去輕輕的「咻」，落下「啪」一下 |

土豆和小朋友的聲音和兄弟 APP 一樣，是這樣做的：
- 用一個嗡嗡聲（像聲帶），通過幾個共鳴（像嘴巴的形狀），做出「咕？」「嘿嘿」「哈～啊～嗯」「耶」這些聲音；嘴巴的形狀可以慢慢變，例如「啊」變「喔」再閉起來變「嗯」。
- 搖籃曲的哼歌也是一樣的方法，嘴巴閉著，所以幾乎只剩最低的那個音，聽起來軟軟的。
- 一群「耶！」是七個小小的聲音，每個高低、快慢都有一點不一樣，一個接一個疊起來。
- 挖土、風、翻紙、魔法的「咻」，用沙沙的雜音通過會移動的共鳴合成。
