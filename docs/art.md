# 圖的約定：圖和程式共用

迷宮是程式每次重新產生的，所以路不是一張大圖，而是**一格一格的路塊**拼起來的。每個世界、每種畫風都有一套路塊、背景、主角、終點、裝飾和貼紙。圖由 `design/art/` 的 Python 程式產生。

## 三種畫風
- `a`：羊毛氈布書風（預設）：毛氈、縫線、布紋。
- `b`：像素小遊戲風：大方塊像素、少少幾個鮮豔顏色。
- `c`：果凍糖果風：透明亮晶晶的果凍路、糖果裝飾。

三種畫的是同一個世界、同一個迷宮，換畫風時迷宮完全一樣。

## 六個世界（資料夾名稱）
`garden` 花園（小蜜蜂→花）、`tunnel` 地底隧道（土豆→地洞的家）、`sea` 海底（小魚→珊瑚家）、`city` 城市（小公車→公車總站）、`snow` 雪地（小企鵝→企鵝媽媽的冰屋）、`space` 太空（太空人→火箭）。

## 檔案（`app/assets/art/<畫風>/`）
共用：
- `tudou_<pose>.svg`，`viewBox="0 0 200 200"`：小鼴鼠土豆。pose：`wave`（揮手）、`point`（往右指，程式會鏡射）、`cheer`（歡呼）、`sleep`（睡覺）、`peek`（從地洞探出頭，提示用）。

每個世界 `app/assets/art/<畫風>/<世界>/`：
- `bg.svg`，`viewBox="0 0 600 800"`：迷宮的地面（布、草地、沙、海水……），沒有路。程式用「蓋滿」的方式放，可能被裁成 1:1 到 3:4，所以四邊不要放重要的東西。
- `tile_<n>.svg`，n = 1～15，`viewBox="0 0 100 100"`：一格路。n 是四個方向有沒有通的加總：上 1、右 2、下 4、左 8（例如 5 = 上下直路，6 = 右下轉彎，15 = 十字路口）。
  - 路在格子中間，寬 62（從 19 到 81）；通的那一邊要一直畫到格子邊，形狀和花樣要和隔壁的格子接得起來（縫線、像素邊、果凍亮光都要對齊）。
  - 不通的那一邊是圓圓的死路盡頭。格子其他地方透明。
- `hero.svg`，100×100：主角，臉朝右（程式往左走時會鏡射），大約佔格子的八成。
- `home.svg`，100×100：終點（畫在終點那一格上面）。
- `family.svg`，`viewBox="0 0 400 400"`：到家了，主角和家人抱抱的畫面。
- `star.svg`、`key.svg`，100×100：路上撿的星星、鑰匙（程式畫成格子的一半大）。
- `gate.svg`，100×100：關著的門，擋在一條**左右向**的路上（門是直的）；路是上下向時程式轉 90 度。
- `deco_1.svg`～`deco_6.svg`，100×100：放在沒有路的格子裡的風景（樹、花、石頭、珊瑚……），透明底。
- `sticker_01.svg`～`sticker_10.svg`，`viewBox="0 0 200 200"`：貼紙（圓形，世界裡的東西和朋友）。每走完一關得一張。
- `card.svg`，`viewBox="0 0 300 200"`：首頁的世界卡片圖。

## flutter_svg 的限制
不能用 `<filter>`、`<mask>`、`<style>`／`style=`、CSS、`<text>`、`<image>`、`<pattern>`、混色模式。每個元素都要寫 `fill`／`stroke`。每個檔案小於約 70 KB。用真的 flutter_svg 和 Chromium 比對過（`design/art/build.py fluttercheck`）。
